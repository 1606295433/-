# 轻记 PWA 部署指南

## 快速部署（推荐 Vercel，免费）

### 方法一：Vercel 部署（最简单）

1. 在 [vercel.com](https://vercel.com) 注册账号（用 GitHub 登录即可）
2. 将 `轻记pwa` 文件夹内的所有文件上传到一个 GitHub 仓库
3. 在 Vercel 点击 "New Project" → 导入该仓库 → 点击 Deploy
4. 部署完成后会获得一个类似 `https://qingji-xxx.vercel.app` 的地址
5. 把这个地址发给室友，他们用手机打开后点击"添加到主屏幕"即可安装

### 方法二：GitHub Pages 部署

1. 创建一个 GitHub 仓库（如 `qingji-app`）
2. 将 `轻记pwa` 文件夹内所有文件上传到仓库
3. 进入仓库 Settings → Pages → Source 选择 `main` 分支 → Save
4. 等待几分钟后访问 `https://你的用户名.github.io/qingji-app/`

### 方法三：本地电脑托管（适合测试）

1. 确保电脑已安装 Python
2. 打开命令提示符，进入 `轻记pwa` 文件夹：
   ```
   cd D:\原神\记账\轻记pwa
   python -m http.server 8080
   ```
3. 电脑浏览器访问 `http://localhost:8080` 即可使用
4. 同一 WiFi 下的手机访问 `http://你电脑的IP:8080` 也可使用

## 手机安装方法

### iPhone (Safari)
1. 用 Safari 打开部署后的网址
2. 点击底部「分享」按钮（方框+向上箭头）
3. 选择「添加到主屏幕」
4. 点击右上角「添加」

### Android (Chrome)
1. 用 Chrome 打开部署后的网址
2. 点击右上角三个点菜单
3. 选择「添加到主屏幕」或「安装应用」
4. 点击「安装」

## 自动更新说明

应用使用了 Service Worker 技术。当你更新了源文件后，室友下次打开应用时（需要联网），会自动拉取最新版本。无需手动操作。

如果你修改了代码，记得同步更新 `sw.js` 中的缓存版本号（如 `qingji-v1` 改为 `qingji-v2`），这样会触发客户端更新。

## 数据说明

### 当前版本
- 数据保存在手机浏览器的 localStorage 中
- 支持通过「更多 → 导出数据」备份为 JSON 文件
- 支持通过「更多 → 导入数据」从备份文件恢复
- 建议定期导出备份，以防清除浏览器数据

### 共享账本
- 通过团体码机制实现小群组共享
- 当前版本为本地模拟，后续可接入云数据库实现真正的多人同步

### 数据安全建议
1. 定期使用「导出功能」备份数据到文件
2. 不要清除浏览器数据/网站数据
3. 如需换手机，先导出旧数据，再在新手机导入
